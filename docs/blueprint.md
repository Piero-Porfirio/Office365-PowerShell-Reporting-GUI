# **App Name**: PowerShell GUI

## Core Features:

- Command Execution: Execute PowerShell commands: Allow users to input and execute Office 365 and Azure PowerShell commands via a GUI.
- Result Display: Display Results: Display the results of the PowerShell commands in a readable format within the GUI.
- Reporting: Reporting: Generate basic reports based on the PowerShell command outputs.

## Style Guidelines:

- Dark Mode: Primarily dark background with lighter text for comfortable prolonged use.
- Accent color: Use a vibrant blue (#3498db) for interactive elements and highlights to maintain a sleek look.
- Clean Layout: Well-organized layout with clear sections for command input, results display, and reporting.
- Modern Icons: Use a set of consistent, minimalist icons for actions and navigation.
- Subtle Transitions: Use subtle transitions and animations for feedback and to improve user experience (e.g., loading indicators).
