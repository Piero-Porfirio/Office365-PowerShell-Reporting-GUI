
# Office365-PowerShell-Reporting-GUI

> This project is a GUI-based reporting tool designed to streamline and simplify common Azure and Office 365 administrative functions. It empowers administrators by leveraging the robust capabilities of PowerShell to generate detailed reports and provide actionable insights into their cloud environments.

# Key Features

*   **User Sign-in Analysis:** Generate reports on user sign-in locations, last log-on summaries, external sign-ins, guest sign-ins, and more.
*   **Device Compliance Reporting:** Get insights into non-compliant and unmanaged device sign-ins.
*   **Authentication Analysis:** Analyze MFA failures, 2FA authentication methods, and conditional access failures.
*   **Risk Assessment:** Monitor sign-in risk levels, unlikely travel, and anonymous IP sign-ins.
*   **Intuitive GUI:** Interact with your Azure and Office 365 data through a user-friendly graphical interface, no need to remember complex PowerShell commands.
*   **Intune Reporting:** Retrieve a list of all Intune applications.

# Installation

This application requires Node.js, npm, and PowerShell to be installed.

1.  **Clone the repository:** bash git clone https://github.com/piero-porfirio/Office365-PowerShell-Reporting-GUI.git
2.  **Navigate to the project directory:** bash cd Office365-PowerShell-Reporting-GUI
3.  **Install dependencies:** bash npm install
4.  This command will install all the necessary Node.js packages listed in the `package.json` file.
5.  **Configure your environment:**

    *   This project will need access to your Azure and Office 365 environment. Please see the Microsoft documentation on how to set up the appropriate access, rights, and permissions to your Azure Active Directory and Office 365 environments.
    *   Ensure that PowerShell is properly configured and you can connect to your Azure and Office 365 environments from within PowerShell.

5.  **Run the application:** bash npm run dev
6.  *   This command starts the application in development mode. You can typically access it in your browser at `http://localhost:9002` (or a similar address, as specified in the console output).
    *   The number `9002` is the port that is used for the app; this is defined in the `package.json` file.

## Important Requirements

*   **Node.js:** The user needs to have Node.js installed on their local machine. You can download it from [https://nodejs.org/](https://nodejs.org/).
*   **PowerShell:** The user needs to have PowerShell installed on their local machine and properly configured to connect to their Azure and Office 365 environments.
*   **Environment:** The app will need to connect to Azure and Office365. Make sure you provide instructions on how to set that up.

## Usage

1.  **Launch the application:** Once the app is running (using `npm run dev`), open your web browser and navigate to `http://localhost:9002` (or the URL specified in the console).
2.  **Authenticate:** The application will prompt you to authenticate with your Azure/Office 365 credentials.
3.  **Navigate:** Use the GUI to select the desired report type or administrative function.
4.  **View Reports:** View and analyze the generated reports.

## Cloning the Repository

1.  **Open a Terminal or Command Prompt:** Open a terminal or command prompt on your local machine.
2.  **Navigate to the Desired Directory:** Navigate to the directory where you want to save the project. You can do so using the `cd` command.
3.  **Clone the project:** Run the following command to clone the project.
4.  bash git clone https://github.com/piero-porfirio/Office365-PowerShell-Reporting-GUI.git
5.  This will download all the project files to your local machine.
